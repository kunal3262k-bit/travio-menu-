# DineFlow Troubleshooting Guide

If you experience any issues with DineFlow, follow these steps to resolve them quickly.

## 1. Kitchen is not receiving orders
- **Check Wi-Fi**: Ensure the kitchen tablet is connected to the internet.
- **Refresh the page**: Pull down to refresh or click the browser refresh button.
- **Check System Health**: Go to your Admin Dashboard and click on **Health**. If the Realtime Engine (Socket.IO) says "Disconnected", contact support immediately.

## 2. Customer menu says "Temporarily Unavailable"
- Check your **Restaurant Status** in **Settings > Operations**. Ensure it is set to **LIVE**. If it is set to PAUSED or SETUP, customers cannot see the menu.

## 3. QR Code is not scanning
- Ensure the QR code is printed at least 2x2 inches.
- Ensure the print quality is high (no smudges).
- Try wiping the QR code if it is covered by a plastic/acrylic stand.
- If it still fails, reprint the QR code from the **Setup > Tables** page.

## 4. Item is showing as available but we are out of stock
- Go to **Admin > Menu Availability** and ensure the item is toggled to **Sold Out**.
- The customer may have opened the menu before you marked it sold out. If they try to place the order, the system will reject it.

## Need Help?
If these steps don't solve your issue, please contact your DineFlow account manager directly on WhatsApp.
