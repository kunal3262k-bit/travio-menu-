# SwiftTab Kitchen Guide

This guide is for the kitchen staff operating the Kitchen Display System (KDS).

## 1. Viewing Orders
Keep a tablet or laptop open to the Kitchen Dashboard (`/kitchen`).
- When a customer places an order, you will hear a **"Ding!"** and the order ticket will appear on screen.
- Orders are sorted by time. The oldest order is always at the top left.

## 2. Managing Order Status
Every ticket has a button at the bottom:
1. **Accept Order**: Click this as soon as you start cooking. The customer will see the status change to "Preparing".
2. **Mark Ready**: Click this when the food is plated and ready for the waiter to pick up. The waiter will be notified.

## 3. Item Availability (86'ing)
If you run out of an ingredient:
1. Go to **Admin > Menu Availability**.
2. Find the item and toggle the switch to **Sold Out**.
3. It will instantly disappear from the customer's digital menu so no one can order it.
4. Remember to toggle it back to **Available** when the ingredient is restocked.
